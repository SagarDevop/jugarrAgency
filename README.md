# Jugarr — Web Development & Digital Solutions Studio

Official website for **Jugarr** ([jugarr.in](https://jugarr.in)), founded by Sagar Singh Rajawat. Built with Next.js 16 (App Router), React 19, Tailwind CSS, and GSAP.

## Features & Architecture

- **Next.js 16 App Router**: Server-side rendering (SSR) and Static Site Generation (SSG) with zero-layout-shift performance.
- **Technical SEO & Structured Data**: Server-rendered metadata, dynamic XML sitemap, custom canonical tags, and JSON-LD schemas (`Organization`, `WebSite`, `Person`, `Service`, `BreadcrumbList`, `BlogPosting`).
- **Dedicated Service Landing Pages**: Deep architecture covering E-Commerce, Business Websites, and Custom Full-Stack Web Applications.
- **Client Case Studies**: Verified engineering breakdowns and before/after comparisons for Bandamart and 4 Lotus Interior.
- **The Jugarr Journal**: Technical insights, performance optimization strategies, and Core Web Vitals best practices.
- **Micro-Interactions**: Smooth GSAP animations, Lenis smooth scrolling, and custom UI components.

## Getting Started

### Prerequisites
- Node.js 18.18+ or 20+

### Installation
```bash
npm install
```

### Local Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm start
```
